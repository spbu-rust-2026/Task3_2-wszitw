# Kitty



Котёнок Kitty работает эмулятором терминала и старается запомнить, какие команды выполнялись недавно. Память у него ограничена: когда появляется новая команда, самой старой приходится уступить ей место.

## Задача

Симулятор терминала хранит последние `k` выполненных команд. Когда приходит новая команда, она добавляется в историю. Если после добавления элементов стало больше `k`, удалите самую старую команду.

## Интерфейс для тестов

Реализуйте и экспортируйте из `src/lib.rs` функцию:

```rust
pub fn add_command(
    history: &mut std::collections::VecDeque<String>,
    command: String,
    k: usize,
)
```

Функция должна добавить команду в конец истории и удалить самые старые команды, если после добавления размер истории превышает `k`.

## Рекомендации

- Перед началом работы самостоятельно создайте Rust-проект в этой папке командой `cargo init --name task3_2_template`.

- Для хранения истории используйте двустороннюю очередь (`VecDeque`).
- Проверьте поведение при заполнении истории и при добавлении команды в уже заполненную историю.
- Автоматические тесты находятся в `tests/assignment.rs`; запускайте их командой `cargo test`.
- После реализации запустите `cargo fmt` и `cargo check`.
